# BCL Portal Development Roadmap

이 로드맵은 Antigravity 에이전트 연합이 BCL Portal을 완성해가는 12주간의 여정을 정의합니다.

**에이전트**: Architect (Opus), Senior Dev (Opus), Developer (Sonnet), UI Developer (Gemini), Specialist (Gemini)

---

## Phase 1: Foundation (Weeks 1-2)
**Lead: Architect (Opus 4.6 Thinking)**
- [ ] Database schema finalization
- [ ] RLS (Row Level Security) policies implementation
- [ ] Authentication system setup (Supabase Auth)
- [ ] Core API structure & Middleware design

## Phase 2: Core Features (Weeks 3-6)
**Lead: UI Developer (Gemini) + Developer (Sonnet), Review: Architect (Opus)**
- [ ] Admin portal basic features (Insights, Finance, CRM)
- [ ] Member app basic features (Profile, Notices)
- [ ] Coach app basic features (Dashboard, Member list)
- [ ] Core Booking system implementation

## Phase 3: Advanced Features (Weeks 7-10)
**Lead: Mixed Specialists**
- [ ] Payment integration (Senior Dev - Opus)
- [ ] Class portal & Real-time timer (UI Dev + Specialist - Gemini)
- [ ] Kiosk system for check-in (UI Dev + Specialist - Gemini)
- [ ] Race system integration (UI Dev + Specialist - Gemini, Review: Opus)

## Phase 4: Polish & Testing (Weeks 11-12)
**Lead: All Agents**
- [ ] E2E testing & QA (Developer - Sonnet)
- [ ] Performance optimization (Specialist - Gemini)
- [ ] Security audit & Penetration testing (Architect + Senior Dev - Opus)
- [ ] Documentation completion & Final handoff (Developer - Sonnet)
