# BCL Portal Development Roadmap

이 로드맵은 Antigravity 에이전트 연합이 BCL Portal을 완성해가는 12주간의 여정을 정의합니다.

---

## Phase 1: Foundation (Weeks 1-2)
**Lead: Architect (Opus)**
- [ ] Database schema finalization
- [ ] RLS (Row Level Security) policies implementation
- [ ] Authentication system setup (Supabase Auth)
- [ ] Core API structure & Middleware design

## Phase 2: Core Features (Weeks 3-6)
**Lead: Developer (Sonnet), Review: Architect (Opus)**
- [ ] Admin portal basic features (Insights, Finance, CRM)
- [ ] Member app basic features (Profile, Notices)
- [ ] Coach app basic features (Dashboard, Member list)
- [ ] Core Booking system implementation

## Phase 3: Advanced Features (Weeks 7-10)
**Lead: Mixed Specialists**
- [ ] Payment integration (Opus)
- [ ] Class portal & Real-time timer (Gemini)
- [ ] Kiosk system for check-in (Gemini)
- [ ] Race system integration (Gemini + Opus)

## Phase 4: Polish & Testing (Weeks 11-12)
**Lead: All Agents**
- [ ] E2E testing & QA
- [ ] Performance optimization (Gemini)
- [ ] Security audit & Penetration testing (Opus)
- [ ] Documentation completion & Final handoff (Sonnet)
