# New Page Addition Workflow

이 워크플로우는 프로젝트의 규칙(Sitemap SSOT)을 준수하며 새로운 기능을 안전하게 추가하는 절차를 정의합니다.

## 단계별 절차

1. **Sitemap 수정**
   - `.docs/sitemap/README.md` 및 해당 모듈 파일(`.docs/sitemap/**/*.md`)을 열어 새로운 메뉴/라우트의 위치와 상세 기능을 정의합니다.
   - **이 단계가 완료되기 전에는 코드를 작성하지 않습니다.**

2. **Database 설계 (필요 시)**
   - 새로운 데이터가 필요한 경우 `db-migration` 스킬을 사용하여 마이그레이션 SQL을 작성하고 적용합니다.

3. **Page 컴포넌트 생성**
   - 사용자(`apps/*`) 또는 관리자(`admin/*`) 경로에 `page.js`를 생성합니다.
   - 이때 `ui-gen` 스킬을 참고하여 프로젝트 테마에 맞는 Glassmorphism 디자인을 적용합니다.

4. **레이아웃/네비게이션 연결**
   - `layout.js`의 네비게이션 배열에 새 페이지를 추가하여 사용자가 진입할 수 있게 합니다.

5. **기획 문서(Sitemap) 최종 갱신**
   - 구현 과정에서 변경된 세부 사항(필드명, 버튼 액션 등)을 다시 기획 문서(`.docs/sitemap/**/*.md`)에 반영하여 **코드와 기획을 완전히 동기화**합니다.

6. **검증 및 커밋**
   - 화면이 정상적으로 렌더링되는지 확인합니다.
   - `commit-bot` 스킬을 사용하여 변경 사항을 커밋합니다.
