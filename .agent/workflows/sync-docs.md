# Documentation Sync Workflow

이 워크플로우는 소스 코드의 실제 구현 내용을 바탕으로 기획 문서(`.docs/sitemap/*.md`)를 최신화할 때 사용합니다.

## 단계별 절차

1. **소스 코드 분석**
   - 최근 수정된 파일 또는 동기화가 필요한 대상 페이지의 `page.js` 및 관련 컴포넌트를 읽습니다.
   - 실제 사용된 UI 텍스트, 데이터 필드, API 엔드포인트, 버튼 기능을 추출합니다.

2. **기획 문서 대조**
   - `.docs/sitemap/**/*.md` 파일에서 해당 기능에 대한 기술 내용을 찾습니다.
   - 현재 구현된 코드와 문서 사이의 차이점(누락된 필드, 변경된 라우트 등)을 식별합니다.

3. **기획서 업데이트**
   - 식별된 차이점을 바탕으로 기획 문서를 수정합니다.
   - 단순한 기능 나열이 아닌, 실제 소스의 동작 방식이 정확히 기술되도록 합니다.

4. **최종 정합성 확인**
   - 수정된 문서가 사이트맵 전체 구조와 충돌하지 않는지 확인합니다.
   - `commit-bot` 스킬을 사용하여 문서 수정 내역을 커밋합니다.
