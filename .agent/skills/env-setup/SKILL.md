# Environment Setup Skill (env-setup)

이 스킬은 새로운 개발 환경이나 에이전트 세션이 시작될 때 BCL Portal 프로젝트가 정상적으로 작동하기 위한 필수 도구들을 점검하고 초기화합니다.

## 1. 주요 점검 및 세팅 항목
1. **Node.js 환경**: 프로젝트에 적합한 Node.js 버전(v18 이상) 및 npm 패키지 매니저 유무 확인.
2. **Python 환경**: 파이썬 3(v3.9 이상) 및 pip 패키지 매니저 유무 확인 (레이스 모듈 등에서 사용).
3. **패키지 의존성**: `npm install` 및 파이썬 `requirements.txt`를 통한 최신 의존성 설치.
4. **환경 변수**: `.env.local` 또는 `.env` 파일의 존재 여부 및 필수 키(Supabase URL, Key 등) 점검.
5. **가상화 환경 (Docker)**: Docker 및 Docker Compose 설치 상태 확인 (멀티 컨테이너 아키텍처 구동용).
6. **외부 도구**: Supabase CLI 등 프로젝트 운영에 필요한 외부 소프트웨어 설치 상태 확인.
7. **빌드 및 컨테이너 검증**: 프로젝트가 정상적으로 빌드(`npm run build`)되거나 도커 이미지 생성이 가능한지 확인.

## 2. 사용 시점
- 새로운 개발 환경(예: 신규 PC, 서버)에서 처음 작업을 시작할 때.
- 장기간 작업이 중단되었다가 다시 재개하여 의존성 버전이 맞지 않을 때.
- 환경 변수 설정 오류로 인해 시스템이 작동하지 않을 때.

## 3. 실행 프로세스
1. **의존성 확인**: `scripts/setup.sh`를 실행하여 필수 소프트웨어 존재 여부를 확인합니다.
2. **의존성 설치**: 누락된 경우 `npm install` 등을 통해 자동으로 설치를 시도합니다.
3. **환경 설정**: `.env.example`을 참고하여 환경 변수 파일 생성을 안내하거나 생성합니다.
4. **상태 보고**: 모든 설정이 완료되면 에이전트와 사용자에게 준비 상태를 보고합니다.

## 4. 커맨드 예시
- `sh .agent/skills/env-setup/scripts/setup.sh`
