## 🚨 High-Risk Issues

1. **보안: transactions 테이블 RLS 비활성**
   - 현재 `transactions` 테이블에 누구나 접근 가능한 상태임. 결제 내역 누출 및 위조 위험.
   - 조치: RLS 활성화 및 `member_id` 기반 Policy 즉시 적용 필요.

2. **기능: Edge Function 파일 누락**
   - `confirm-payment`, `sync-pg-settings` 함수가 파일 시스템(`supabase/functions/`) 내에 존재하지 않음.
   - 결과: 결제 프로세스가 프론트엔드에서 중단됨 (404/Function not found).

3. **기능: DB 마이그레이션 미적용**
   - `pg_settings`, `refunds` 테이블이 DB에 생성되지 않았으며 `transactions` 컬럼 확장도 이루어지지 않음.
   - 결과: 결제 시도 시 DB Insert 에러 발생.

4. **품질: 빌드 실패 (TypeScript Error)**
   - `admin/dashboard/page.tsx`에서 존재하지 않는 프로퍼티(`revenueYoY`) 참조로 인해 `npm run build` 실패.

## ✅ Recommendations

1. **즉시 조치**: 누락된 Edge Function 코드를 복구/생성하고 `supabase functions deploy` 수행.
2. **인프라 반영**: `supabase migration up` 또는 MCP를 통해 최신 마이그레이션을 운영 DB에 적용.
3. **보안 강화**: `transactions` 테이블 RLS를 활성화하고 `20260218230000` 마이그레이션에 정의된 Policy를 강제 적용.
4. **빌드 수정**: Dashboard의 TS 에러(`revenueYoY` 관련)를 해결하고 빌드 성공 확인 후 Deploy.
