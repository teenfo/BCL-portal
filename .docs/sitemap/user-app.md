# User Application Design Module (`/apps/*`)

이 문서는 일반 회원용 모바일 웹 앱의 화면 구조, 주요 기능 및 기술적 설계를 통합 관리하는 정본(SSOT) 기획서입니다.

---
> [!NOTE]
> 전체 서비스 구조 및 공통 라우팅 규칙은 [**Global Sitemap Index**](./README.md)를 참고하십시오.


## 1. 📱 네비게이션 및 화면 구조 (Bottom Tab)

회원용 앱은 한 손 조작이 용이하도록 하단 탭 네비게이션 기반의 모바일 퍼스트 디자인을 따릅니다.

### 1) Home (`/apps/dashboard`)
- **수업 요약**: 본인의 오늘 예약/체크인 상태 및 다음 수업 스케줄 명시.
- **주요 소식**: 지점 긴급 공지사항 및 개인별 알림 피드.
- **멤버십 정보**: 이용 증인 플랜 종류 및 만료일 D-Day 표시.

### 2) Schedule (`/apps/schedule`)
- **수업 캘린더**: 주간 단위 수업 목록 조회 및 코치/난이도별 실시간 필터링.
- **예약 프로세스**: 실시간 예약, 대기열(Waitlist) 등록 및 원클릭 취소.
- **내 일정**: 과거 참여 이력 및 예정된 예약 내역 통합 관리.

### 3) Check-in (`/apps/checkin`)
- **QR 체크인**: 입장 단말기 태깅을 위한 실시간 동적 QR 코드 생성.
- **출석 월력**: 본인의 월간 출석 데이터 및 운동 통계 시각화.

### 4) Facilities (`/apps/facilities`)
- **지점 안내**: 운영 중인 전 지점 정보(운영 시간, 주소, 지도, 편의시설) 조회.
- **데이터 연동**: 관리자 포털의 실시간 지점 설정 동기화.

### 5) Profile (`/apps/profile`)
- **내 정보**: 기본 프로필 수정, 앱 설정(다크모드 등) 관리.
- **구독/결제**: 현재 이용권 상세, 잔여 횟수 확인 및 과거 결제 영수증 조회.
- **고객 센터**: 1:1 문의 채널 및 푸시 알림 수신 설정.

## 2. 🛠️ 기술 아키텍처 및 UI 원칙

### 기술 스택
- **Architecture**: Next.js CSR 기반의 모바일 특화 반응형 레이아웃.
- **Data Layer**: Supabase `anon key` 및 RLS 정책을 통한 안전한 본인 데이터 접근.
- **Security**: 모든 라우트 접근 시 세션 유효성 자동 검증.

### 디자인 원칙
- **Mobile-First UX**: 하단 탭 배치 및 엄지손가락 조작 반경 내 중요 액션 버튼 배치.
- **Glassmorphism**: BCL Orange 아이덴티티를 강조하는 반투명 유리 질감의 프리미엄 UI.

## 🚀 3. 회원 사용 가이드 요약 (User Guide)
- **입장하기**: 앱 하단 중앙 '체크인' 탭을 누르고 QR을 입구 단말기에 스캔하세요.
- **수업 예약**: '스케줄' 탭에서 원하는 날짜를 선택하고 '예약하기'를 누르면 완료됩니다.
- **멤버십 확인**: '홈' 또는 '프로필' 화면에서 남은 기록권 횟수와 만료일을 실시간으로 확인하세요.
