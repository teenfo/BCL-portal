# Admin Settings & Facility Functional Design

## 개요
시설의 기본 정보, 운영 정책, 시스템 설정을 관리한다.

## 1. 지점/시설 정보 (`/admin/settings/facility`)
- **기본 프로필**: 지점 명칭, 주소, 연락처, 대표자 정보.
- **운영 시간**: 요일별 오픈/클로즈 시간, 브레이크 타임 설정.
- **이미지 관리**: 시설 전경 및 내부 사진 업로드 (사용자 앱 노출용).

## 2. 운영 정책 (`/admin/settings/policies`)
- **예약/취소 규정**: 수업 시작 몇 시간 전까지 취소 가능한지, 노쇼 페널티 설정.
- **이용 약관**: 서비스 이용 약관, 개인정보 처리방침, 환불 규정 텍스트 관리.

## 3. 권한 정책/역할 관리 (`/admin/settings/roles`)
- **관리자 계정**: 부관리자 계정 생성 및 권한 수준 부여 (Owner, Manager, Staff).
- **메뉴 접근 제어**: 역할에 따른 어드민 메뉴 노출/차단 설정.

## UX/UI 요구사항
- **즉시 반영**: 설정 변경 시 사용자 앱에 실시간으로 반영되어야 함.
- **변경 이력**: 누가 언제 어떤 설정을 변경했는지 로깅(Audit Log) 필수.
