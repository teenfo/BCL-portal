# Class Portal Functional Design (Live Class Hub)

## 개요
수업 현장에서 코치와 회원이 실시간으로 수업 내용을 확인하고, 운동 퍼포먼스를 관리하기 위한 전용 포털이다. 센터 내 대형 스크린이나 태블릿 환경에 최적화된 UI를 제공한다.

## 1. 라이브 클래스 대시보드 (`/class/live`)
- **현재 수업 정보**: 실시간 시간 기준으로 현재 진행 중인 수업명, 담당 코치, 남은 시간 노출.
- **참여 회원 리스트**: 현재 체크인된 회원 명단 및 상태 표시.
- **수업 공지**: 해당 클래스 타임에 전달할 코치의 특이사항 실시간 공지.

## 2. 실시간 WOD (Workout of the Day) 표시
- **운동 프로그램 노출**: 오늘 설정된 WOD의 구성(Warm-up, Strength, Metcon 등)을 큰 글씨와 시각적 요소로 표시.
- **동작 가이드**: WOD에 포함된 주요 동작 및 스케일링 옵션 안내.
## 4. 실시간 리더보드 (`/class/leaderboard`)
- **실시간 순위**: 세션 참여자들의 기록(와드 결과)을 실시간으로 취합하여 순위 표시.
- **기록 공유**: 개인별 운동 성과를 시각적으로 비교하며 경쟁심 유발.

## 3. 워크아웃 타이머 (`/class/timer`)
- **다양한 모드 지원**: 
  - **Count Up / Down**: 일반적인 시간 측정 및 카운트다운.
  - **AMRAP** (As Many Rounds As Possible): 설정된 시간 동안의 지속 라운드 측정.
  - **EMOM** (Every Minute on the Minute): 1분 단위 반복 알림.
  - **Tabata**: 고강도 인터벌 타이머 (20초 운동 / 10초 휴식 등 커스텀 가능).
- **시각/청각 피드백**: 시작/종료/휴식 시 신호음 및 색상 변화로 진행 상황 전달.

## UX/UI 요구사항
- **고대비 디자인**: 체육관 멀리서도 잘 보일 수 있도록 검정 배경에 흰색/오렌지색 중심의 고대비 UI 적용.
- **키오스크/TV 최적화**: 마우스 조작보다는 터치나 리모컨 환경을 고려한 큼직한 버튼과 레이아웃.
- **풀스크린 지원**: 브라우저 전체 화면 모드를 기본적으로 고려하여 설계.
