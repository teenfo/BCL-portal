# Admin Session & Schedule Functional Design

## 개요
수업(세션) 일정을 생성, 수정하고 회원들의 예약을 관리한다.

## 1. 세션·수업 스케줄 (`/admin/sessions/schedule`)
- **캘린더 뷰**: 주 단위/월 단위 수업 일정 확인.
- **세션 생성**: 수업명, 담당 코치, 시간, 장소, 최대 정원, 난이도 설정.
- **반복 일정**: 주간 반복 수업 자동 생성 기능.

## 2. 예약·대기열 관리 (`/admin/reservations`)
- **예약 내역**: 특정 세션의 예약자 명단 확인 및 상태 변경 (확정, 취소, 노쇼).
- **대기열 관리**: 정원 초과 시 대기 순번 관리 및 취소 발생 시 자동/수동 배정.
- **일괄 알림**: 세션 변경/취소 시 예약자들에게 푸시/SMS 알림 발송.

## 3. 코치 배정·교체 (`/admin/sessions/assignments`)
- **코치 가용성**: 코치별 개인 일정과 겹치지 않게 수업 배정.
- **대체 코치**: 긴급 상황 발생 시 수업 담당 코치 변경 기능.

## UX/UI 요구사항
- **드래그 앤 드롭**: 캘린더 상에서 수업 시간을 마우스로 조정 가능 (컴퓨터 환경 최적화).
- **상태 색상 구분**: 예약 완료, 정원 마감, 취소됨 등을 색상으로 직관적 표시.
