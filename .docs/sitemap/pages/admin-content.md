# Admin Content & Notice Functional Design

## 개요
공지사항, 배너, 앱 내 콘텐츠를 관리하여 사용자에게 정보를 전달한다.

## 1. 공지사항 관리 (`/admin/content/notices`)
- **게시글 작성**: 제목, 내용(에디터 지원), 첨부파일, 대상(전체/특정 그룹) 설정.
- **예약 게시**: 특정 일시에 공지가 노출되도록 예약 설정.
- **중요 공지**: 목록 상단 고정 및 푸시 알림 연동 여부 선택.

## 2. 배너 및 팝업 (`/admin/content/banners`)
- **이미지 업로드**: 고화질 배너 이미지 등록 및 랜딩 URL 연결.
- **노출 기간**: 프로모션 기간에 맞춰 자동 노출/비노출 처리.

## 3. 게시글 관리 (`/admin/content/posts`)
- **커뮤니티 모니터링**: 사용자 커뮤니티 게시글 필터링 및 직접 관리.

## 4. 댓글/신고 관리 (`/admin/content/moderation`)
- **신고 처리**: 부적절한 댓글 또는 게시글 신고 내역 차단 및 작성자 제재.

## UX/UI 요구사항
- **WYSIWYG 에디터**: 폰트 스타일, 이미지 삽입 등이 간편한 에디터 적용.
- **미리보기**: 앱에서 어떻게 보이는지 실시간 미리보기 기능 제공.
