# Admin Dashboard Functional Design

## 개요
관리자 포털의 메인 화면으로, 시설 운영 현황을 한눈에 파악할 수 있는 지표와 요약 정보를 제공한다.

## 주요 기능 (KPI Metrics)
- **신규 회원 (7일)**: 최근 7일간 가입한 신규 회원 수 및 전주 대비 증감율.
- **오늘의 예약**: 금일 예정된 수업 예약 총건수.
- **현재 시설 이용**: 현재 체크인 상태인 활성 이용자 수.
- **미처리 문의**: 아직 답변이 완료되지 않은 고객 문의 건수.

## 차트 및 통계 (Visual Analytics)
- **주간 방문자 추이**: 최근 7일간의 일별 체크인 건수 그래프.
- **세션 점유율**: 인기 있는 수업 시간대 및 세션 유형별 예약 비중 차트.

## 실시간 현황 (Real-time Status)
- **최근 체크인 내역**: 가장 최근에 입장한 회원 5명의 목록 (이름, 시간, 상태).
- **긴급 공지/일정**: 금일 발생하는 주요 운영 이슈나 긴급 수업 변경 사항 요약.

## UX/UI 요구사항
- **반응형 대시보드**: 위젯 형태로 구성하여 화면 크기에 따라 유연하게 배치.
- **데이터 새로고침**: 수동 새로고침 버튼 및 주기적 자동 갱신 (선택 사항).
