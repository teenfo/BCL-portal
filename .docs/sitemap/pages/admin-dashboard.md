# Admin Dashboard Functional Design

## 개요
관리자 포털의 메인 화면으로, 시설 운영 현황을 한눈에 파악할 수 있는 지표와 요약 정보를 제공한다.

## 주요 기능 (KPI Metrics)
현재 Supabase와 연동되어 실시간 데이터를 표시하는 지표:
- **총 회원 수**: 전체 등록된 회원 수.
- **전체 세션**: 개설된 전체 수업/세션 수.
- **오늘의 체크인**: 금일 발생한 체크인 총건수.
- **등록된 공지**: 게시된 전체 공지사항 수.

## 차트 및 통계 (Visual Analytics)
- **주간 방문자 추이**: 최근 7일간의 요일별 방문자 수 그래프 (현재 Mock Data 사용 중).

## 대시보드 위젯 (Widgets)
- **실시간 알림 (Real-time Notifications)**:
    - 회원 체크인, 수강권 만료 임박, 신규 공지 등 주요 이벤트 타임라인 (Mock Data).
- **오늘의 수업 일정 (Today's Schedule)**:
    - 수업명, 시간, 예약 현황(예약자/정원) 리스트 (Mock Data).
- **시설 상태 (Facility Status)**:
    - 메인 센터, GX 룸, 탈의실/샤워실 등의 운영/청소 상태 표시 (Mock Data).

## UX/UI 특징
- **반응형 그리드 레이아웃**: 상단 KPI 카드, 중단 차트/알림, 하단 일정/시설 상태로 구성.
- **프리미엄 디자인**: 어두운 배경(Dark Theme)과 Glassmorphism 효과 적용.
- **애니메이션**: 페이지 로드 시 Fade-in 효과 및 그래프 애니메이션.

# Admin Access Control (권한 제어)

## 개요
관리자 포털 내에서 사용자의 시스템 접근 권한(Role)을 관리하는 페이지입니다.
모든 등록된 사용자를 조회하고, 각 사용자의 역할을 `Member`(일반 회원), `Coach`(코치), `Admin`(관리자) 중 하나로 지정할 수 있습니다.

## 경로
- `/admin/access-control`

## 주요 기능
- **사용자 통계 (User Stats)**:
    - 전체 사용자 중 Admin, Coach, Member의 수를 실시간으로 집계하여 상단 카드 위젯으로 표시합니다.
- **사용자 검색**:
    - 이름 또는 이메일로 특정 사용자를 빠르게 검색할 수 있습니다.
- **역할 관리 (Role Management)**:
    - 사용자 목록 테이블에서 각 사용자의 현재 역할을 확인하고, 드롭다운 메뉴를 통해 즉시 역할을 변경할 수 있습니다.
    - 역할 변경 시 즉각적인 피드백(Alert)을 제공합니다.

## 데이터 구조 (테이블 컬럼)
1.  **이름 (Name)**: 사용자의 전체 이름.
2.  **이메일 (Email)**: 사용자의 이메일 주소 (고유 식별자).
3.  **현재 역할 (Current Role)**: 현재 할당된 시스템 권한 (뱃지 형태로 시각화).
4.  **역할 변경 (Action)**: 권한 수정을 위한 선택(Select) 입력 필드.

## 기술 제약 사항
- 이 페이지는 **Admin 권한**을 가진 사용자만 접근할 수 있어야 합니다.
- 역할 변경은 보안상 민감한 작업이므로, 백엔드(Supabase RPC 또는 RLS)에서 적절한 검증을 거쳐야 합니다.

# Statistics & Reports (통계 리포트)

## 개요
시설 운영의 효율성을 분석하고 의사결정을 지원하기 위한 상세 데이터 리포트 페이지입니다.
출석률, 수업 참여도, 매출 현황 등을 기간별로 조회할 수 있습니다.

## 경로
- **출석 리포트**: `/admin/reports/attendance`
- **수업 리포트**: `/admin/reports/sessions`
- **매출 리포트**: `/admin/reports/revenue`
- **코치 성과 리포트**: `/admin/reports/coaches`

## 주요 리포트 (Key Reports)

### 1. 출석 리포트 (Attendance)
- **목적**: 회원들의 시간대별, 요일별 방문 패턴 분석.
- **주요 지표**:
    - 일별 총 입장객 수.
    - 시간대별 혼잡도 (Heatmap).
    - 노쇼(No-show) 비율.

### 2. 수업 리포트 (Sessions)
- **목적**: GX 및 PT 수업의 인기 및 효율성 분석.
- **주요 지표**:
    - 수업별 평균 예약률.
    - 인기 강사 및 인기 종목 순위.
    - 수업 취소율.

### 3. 매출 리포트 (Revenue) - *준비 중*
- **목적**: 수강권 판매 및 결제 내역 기반 매출 분석.
- **주요 지표**:
    - 월별/일별 총 매출액.
    - 상품별(수강권) 판매 비중.
    - 환불 금액 및 비율.

### 4. 코치 성과 리포트 (Coaches)
- **목적**: 코치별 수업 진행 횟수 및 회원 피드백 분석.
- **주요 지표**:
    - 코치별 월간 수업 시수.
    - 담당 회원 수 및 재등록률.

## 기능 요구사항
- **날짜 필터**: 시작일(Start Date) ~ 종료일(End Date) 범위 설정 기능.
- **데이터 내보내기**: 조회된 통계 데이터를 Excel 또는 CSV로 다운로드하는 기능.
- **차트 시각화**: 변화 추이를 쉽게 파악할 수 있는 선 그래프(Line Chart) 및 막대 그래프(Bar Chart) 제공.
