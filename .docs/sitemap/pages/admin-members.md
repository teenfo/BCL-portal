# Admin Member Management Functional Design

## 개요
센터의 회원 데이터를 관리하고, 개별 회원의 이용 기록, 멤버십 상태, 출결 현황을 상세히 조회한다.

## 1. 회원 목록 (`/admin/members`)
- **검색 및 필터**: 이름, 연락처 검색 / 멤버십 상태(활성, 만료, 대기), 등급별 필터링.
- **일괄 관리**: 선택된 회원에게 알림 전송, 엑셀 다운로드.
- **회원 등록**: 신규 회원 수동 추가 기능 (기본 정보 입력).

## 2. 회원 상세 프로필 (`/admin/members/:memberId`)
- **기본 정보**: 개인정보, 가입일, 최근 방문일.
- **멤버십 이력**: 보유 중인 이용권 내역, 구매/만료 이력 관리.
- **예약/출결 기록**: 해당 회원의 과거 및 향후 예약 내역, 체크인 로그.
- **메모/상담 기록**: 관리자만 볼 수 있는 특이사항 기록.

## 3. 출결·체크인 로그 (`/admin/attendance`)
- **전체 로그 조회**: 특정 날짜/지점별 전체 체크인 내역 리스트.
- **수동 체크인 처리**: QR 스캔이 어려운 경우 관리자가 직접 출석 처리.
- **통계**: 일별/시간대별 방문객 분포 확인.

## UX/UI 요구사항
- **데이터 테이블**: 페이징 처리, 컬럼별 정렬(Sort) 기능 필수.
- **빠른 액션**: 목록에서 바로 전화 걸기(모바일) 또는 메시지 발송 팝업 연결.
