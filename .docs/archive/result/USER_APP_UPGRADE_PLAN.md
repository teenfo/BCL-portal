# BCL 사용자 앱 고도화 마스터 플랜 (Master Plan)

**작성 일자**: 2026-02-17  
**작성자**: Antigravity AI Agent  
**대상**: BCL Portal 사용자 앱 (User Application)

---

## 1. 현재 상태 진단 (Current State)

사용자 앱은 현재 기본 골격과 핵심 기능이 안정적으로 구현되어 있으나, 브랜드 아이덴티티 강화와 사용자 리텐션(Retention) 향상을 위한 고도화가 필요한 단계입니다.

- **완성도**: 약 85% (핵심 기능 정상 작동)
- **강점**: 세련된 Glassmorphism 디자인, 모바일 최적화 내비게이션, 실시간 데이터 연동.
- **약점**: 브랜드 정체성(Header) 부재, 일부 화면 스타일 불일치, 커뮤니티 기능 부족.

---

## 2. [CORE] 탑 헤더 (Top Header) 고도화

가장 우선적으로 개선해야 할 영역으로, 앱의 전체적인 인상과 완성도를 결정합니다.

### 2.1 디자인 사양
- **스타일**: `Sticky Glassmorphism` (상단 고정, 블러 처리된 반투명 배경).
- **효과**: 페이지 스크롤 시 콘텐츠와 자연스럽게 겹치며 깊이감(Depth) 제공.
- **높이**: 56px (모바일 표준).

### 2.2 지능형 레이아웃 구성
- **메인 페이지 (Home/Dashboard, Schedule, etc.)**
    - **Left**: 지점명 (예: `BCL Gangnam`) 또는 로고 심볼.
    - **Center**: **BCL Main Logo (SVG)** - 브랜드 핵심 가치 노출.
    - **Right**: 알림 아이콘(배지 포함) 및 프로필 요약.
- **서브 페이지 (Purchase, Feedback, Records, etc.)**
    - **Left**: **통합 뒤로가기(Back) 버튼**.
    - **Center**: 페이지 타이틀 (예: `이용권 구매`).
    - **Right**: 닫기(`X`) 또는 완료 버튼.

### 2.3 기대 효과
- 브랜드 신뢰도 및 전문성 강화.
- 페이지 내 중복된 헤더 영역 제거를 통한 콘텐츠 가용 면적 확대.
- 일관된 내비게이션 경험(UX) 제공.

---

## 3. 신규 기능 로드맵 (Future Roadmap)

BCL의 특성(CrossFit & Community)을 극대화하기 위한 기능들입니다.

### 3.1 커뮤니티 및 소셜 (Social & Community)
- **🏅 WOD 리더보드**: 오늘의 성적을 공유하고 회원 간 선의의 경쟁 유도.
- **👏 응원하기 (Social Interaction)**: 동료의 기록에 박수를 보내거나 응모 댓글 작성.
- **📢 지점 커뮤니티**: 지점별 공지 및 회원 간 소통 게시판.

### 3.2 코칭 및 콘텐츠 (Coaching Content)
- **🎬 운동 가이드 가이드**: WOD 동작 튜토리얼 영상 및 스트레칭 팁 제공.
- **👨‍🏫 코치 상세 프로필**: 코치진의 경력과 전문 분야 소개로 신뢰 기반 강화.

### 3.3 게임화 및 보상 (Gamification)
- **🎫 디지털 배지 시스템**: 특정 목표 달성 시 시각적으로 화려한 배지 지급.
- **💰 포인트/리워드**: 앱 활동량(출석, 리뷰 등)에 따른 포인트 적립 및 결제 연동.

### 3.4 데이터 인사이트 (Insights)
- **📈 신체 변화 추적**: 인바디 기록 시각화 및 운동 수행 능력 성장 그래프.
- **🔒 내 락커 관리**: 배정된 락커 정보 확인 및 사용 기간 만료 알림/연장.

---

## 4. 실행 계획 (Short-term Actions)

1. **탑 헤더 컴포넌트 개발**: `UserTopHeader.tsx` 생성 및 글로벌 레이아웃 적용.
2. **페이지 최적화**: 기존 페이지들의 파편화된 헤더/로고 영역 제거 및 여백 조정.
3. **디자인 동기화**: `Purchase`, `Feedback` 등 미흡한 화면의 스타일을 Glassmorphism 표준으로 리팩토링.
4. **리더보드 MVP 구축**: `Records` 데이터를 기반으로 한 간단한 일일 기록 공유 화면 기획.
