## 📊 문서 비교 분석 결과

### 조사 보고서에서 발견된 문제점
1. **브랜드 정체성 부족**: 페이지마다 파편화된 헤더/로고 배치
2. **색상 일관성 문제**: Purchase, Feedback 화면에 다크모드 스타일 잔재
3. **미완성 기능**: 필터/검색 UI만 존재하고 실제 로직 미구현
4. **접근성 부족**: ARIA 라벨 누락, 키보드 네비게이션 미흡
5. **성능 최적화 필요**: 번들 크기, 캐싱 전략 부재

### 고도화 계획에서 제시된 방향
1. **탑 헤더 도입**: 브랜드 강화 및 내비게이션 일관성 확보
2. **커뮤니티 기능**: 리더보드, 소셜 인터랙션 추가
3. **게임화**: 배지, 포인트 시스템 도입
4. **콘텐츠 강화**: 운동 가이드, 코치 프로필 상세화

## 🎯 우선순위별 개발 과제

### Phase 1: 기반 강화 (Foundation) - 1-2주
**목표**: 현재 구현된 기능의 완성도를 높이고 일관성 확보

#### 1.1 [CRITICAL] 글로벌 탑 헤더 구현
- **작업**: `UserTopHeader` 컴포넌트 생성 및 레이아웃 통합
- **상세**:
  - Sticky Glassmorphism 스타일 적용
  - 경로별 지능형 레이아웃 (메인 vs 서브페이지)
  - 알림 배지 및 프로필 아바타 통합
- **영향 범위**: 모든 `/apps/*` 페이지
- **예상 공수**: 4-6시간
- **우선순위**: ⭐⭐⭐⭐⭐

#### 1.2 [HIGH] 디자인 시스템 통일
- **작업**: Purchase, Feedback 페이지 스타일 리팩토링
- **상세**:
  - 다크모드 스타일 제거
  - CSS 변수 기반으로 전환 (하드코딩 제거)
  - Glassmorphism 카드 스타일 적용
- **영향 범위**: 
  - `src/app/apps/purchase/page.tsx`
  - `src/app/apps/feedback/page.tsx`
- **예상 공수**: 3-4시간
- **우선순위**: ⭐⭐⭐⭐

#### 1.3 [HIGH] 기존 페이지 헤더 정리
- **작업**: 탑 헤더 도입 후 중복 요소 제거
- **상세**:
  - Dashboard 상단 로고/인사말 영역 간소화
  - Schedule, Profile 등 개별 헤더 제거
  - 여백 및 레이아웃 최적화
- **영향 범위**: Dashboard, Schedule, Profile 등
- **예상 공수**: 2-3시간
- **우선순위**: ⭐⭐⭐⭐

#### 1.4 [MEDIUM] 필터/검색 로직 구현
- **작업**: Schedule 페이지의 필터 및 검색 기능 완성
- **상세**:
  - 코치별 필터링 로직
  - 난이도별 필터링 로직
  - 수업명 검색 기능
- **영향 범위**: `src/app/apps/schedule/page.tsx`
- **예상 공수**: 4-5시간
- **우선순위**: ⭐⭐⭐

#### 1.5 [MEDIUM] 접근성 개선
- **작업**: ARIA 라벨 추가 및 키보드 네비게이션 지원
- **상세**:
  - 모든 버튼에 `aria-label` 추가
  - 포커스 스타일 개선
  - Tab 키 네비게이션 순서 최적화
- **영향 범위**: 전체 컴포넌트
- **예상 공수**: 3-4시간
- **우선순위**: ⭐⭐⭐

### Phase 2: 기능 완성 (Feature Completion) - 2-3주
**목표**: 미완성 기능 구현 및 사용자 경험 향상

#### 2.1 [HIGH] PG 결제 연동
- **작업**: 실제 결제 게이트웨이 통합
- **상세**:
  - Toss Payments 또는 NicePay SDK 연동
  - 결제 성공/실패 플로우 구현
  - 영수증 발급 및 이메일 전송
- **영향 범위**: `src/app/apps/purchase/page.tsx`
- **예상 공수**: 8-10시간
- **우선순위**: ⭐⭐⭐⭐

#### 2.2 [HIGH] 푸시 알림 활성화
- **작업**: Service Worker 기반 Web Push 구현
- **상세**:
  - VAPID 키 생성 및 설정
  - 알림 권한 요청 UI
  - Supabase Edge Function 연동
- **영향 범위**: `public/sw.js`, 알림 시스템
- **예상 공수**: 6-8시간
- **우선순위**: ⭐⭐⭐⭐

#### 2.3 [MEDIUM] 프로필 서브페이지 완성
- **작업**: 미완성 프로필 관련 페이지 구현
- **상세**:
  - 프로필 편집 (이름, 전화번호, 프로필 사진)
  - 알림 설정 (카테고리별 on/off)
  - 결제 내역 상세 조회
- **영향 범위**: `src/app/apps/profile/*`
- **예상 공수**: 6-8시간
- **우선순위**: ⭐⭐⭐

#### 2.4 [MEDIUM] 에러 처리 개선
- **작업**: Toast 컴포넌트 도입 및 에러 메시지 개선
- **상세**:
  - `alert()` 제거 및 Toast로 대체
  - 네트워크 에러 시 재시도 버튼 제공
  - 사용자 친화적 메시지 작성
- **영향 범위**: 전체 페이지
- **예상 공수**: 4-5시간
- **우선순위**: ⭐⭐⭐

### Phase 3: 커뮤니티 기능 (Community Features) - 3-4주
**목표**: 사용자 참여도 및 리텐션 향상

#### 3.1 [HIGH] WOD 리더보드
- **작업**: 일일 기록 공유 및 순위 시스템
- **상세**:
  - Records 데이터 기반 리더보드 생성
  - 성별/연령대별 필터링
  - 실시간 순위 업데이트
- **DB 변경**: `session_feedback` 테이블에 `is_public` 컬럼 추가
- **영향 범위**: 
  - 신규 페이지: `src/app/apps/leaderboard/page.tsx`
  - Dashboard에 프리뷰 위젯 추가
- **예상 공수**: 10-12시간
- **우선순위**: ⭐⭐⭐⭐

#### 3.2 [MEDIUM] 디지털 배지 시스템
- **작업**: 성취 기반 배지 지급 및 표시
- **상세**:
  - 배지 종류 정의 (첫 PR, 100회 출석 등)
  - 자동 지급 로직 (Supabase Trigger)
  - 프로필 페이지에 배지 컬렉션 표시
- **DB 변경**: `member_badges` 테이블 생성
- **영향 범위**: Profile 페이지, Dashboard
- **예상 공수**: 8-10시간
- **우선순위**: ⭐⭐⭐

#### 3.3 [MEDIUM] 친구/팔로우 시스템
- **작업**: 회원 간 소셜 인터랙션
- **상세**:
  - 친구 추가/삭제 기능
  - 친구 기록에 응원(박수) 보내기
  - 친구 활동 피드
- **DB 변경**: `member_follows`, `record_reactions` 테이블 생성
- **영향 범위**: 신규 페이지 및 리더보드 통합
- **예상 공수**: 12-15시간
- **우선순위**: ⭐⭐⭐

### Phase 4: 콘텐츠 강화 (Content Enhancement) - 4-5주
**목표**: 교육 콘텐츠 제공 및 코칭 가치 향상

#### 4.1 [MEDIUM] 운동 가이드 영상
- **작업**: WOD 동작별 튜토리얼 제공
- **상세**:
  - 관리자가 영상 URL 등록 (YouTube/Vimeo)
  - Schedule 페이지에서 수업별 가이드 링크
  - 모달 또는 인앱 플레이어로 재생
- **DB 변경**: `sessions` 테이블에 `guide_video_url` 컬럼 추가
- **영향 범위**: Schedule, Dashboard
- **예상 공수**: 6-8시간
- **우선순위**: ⭐⭐⭐

#### 4.2 [MEDIUM] 코치 프로필 상세화
- **작업**: 코치 소개 및 전문성 강조
- **상세**:
  - 코치별 상세 페이지 (경력, 자격증, SNS)
  - Schedule에서 코치 이름 클릭 시 프로필 이동
  - 1:1 PT 문의 버튼
- **DB 변경**: `coaches` 테이블에 `bio`, `certifications`, `sns_links` 컬럼 추가
- **영향 범위**: 신규 페이지 `src/app/apps/coaches/[id]/page.tsx`
- **예상 공수**: 8-10시간
- **우선순위**: ⭐⭐⭐

#### 4.3 [LOW] 신체 변화 추적
- **작업**: 인바디 기록 및 진행 상황 시각화
- **상세**:
  - 인바디 데이터 입력 폼
  - 체중, 골격근량, 체지방률 그래프
  - 눈바디 사진 비공개 보관함
- **DB 변경**: `body_measurements` 테이블 생성
- **영향 범위**: Profile 또는 Records 페이지
- **예상 공수**: 10-12시간
- **우선순위**: ⭐⭐

### Phase 5: 성능 최적화 (Performance) - 진행 중 병행
**목표**: 로딩 속도 및 사용자 경험 개선

#### 5.1 [MEDIUM] React Query 도입
- **작업**: 데이터 캐싱 및 상태 관리 개선
- **상세**:
  - `@tanstack/react-query` 설치
  - Supabase 쿼리를 React Query로 래핑
  - Prefetching 및 Optimistic Update 적용
- **영향 범위**: 전체 데이터 페칭 로직
- **예상 공수**: 12-15시간
- **우선순위**: ⭐⭐⭐

#### 5.2 [MEDIUM] 컴포넌트 리팩토링
- **작업**: 재사용 가능한 컴포넌트 분리
- **상세**:
  - `<Card>`, `<Button>`, `<Input>`, `<Modal>` 등 공통 컴포넌트 추출
  - Custom Hooks 작성 (`useSessions`, `useMembership` 등)
  - 코드 중복 제거
- **영향 범위**: `src/components/ui/`, `src/hooks/`
- **예상 공수**: 10-12시간
- **우선순위**: ⭐⭐⭐

#### 5.3 [LOW] 이미지 최적화
- **작업**: WebP 포맷 및 Lazy Loading 적용
- **상세**:
  - 모든 이미지를 Next.js Image 컴포넌트로 변환
  - WebP 포맷 사용
  - 뷰포트 밖 이미지 지연 로딩
- **영향 범위**: 전체 이미지 사용 부분
- **예상 공수**: 4-6시간
- **우선순위**: ⭐⭐
