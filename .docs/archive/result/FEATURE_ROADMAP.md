## 📝 **개발 가이드라인**

### **기술 스택**
- **Frontend**: Next.js (CSR), React, TypeScript
- **Styling**: Vanilla CSS + Tailwind CSS
- **Backend**: Supabase (Auth, DB, Realtime)
- **Hosting**: Ubuntu 24.04 (Docker)
- **Payment**: Toss Payments / NicePay
- **Notification**: Kakao Alimtalk

### **디자인 시스템**
- **Primary Color**: #FF6A00 (BCL Orange)
- **Typography**: Inter (현재) / Lexend (예정)
- **UI Style**: Glassmorphism (Dark Mode 기본)
- **Grid**: 8px 기준
- **Roundness**: 8px

### **필수 원칙**
1. **CSR 기반**: 모든 화면은 Client Side Rendering
2. **RLS 필수**: 모든 데이터 접근은 Supabase RLS 정책 준수
3. **Role-based Auth**: AuthGuard로 권한 검증
4. **Sitemap = SSOT**: 모든 화면은 `.docs/sitemap/**/*.md` 기준
5. **문서-코드 동기화**: 기능 개발 시 Sitemap 업데이트 필수
