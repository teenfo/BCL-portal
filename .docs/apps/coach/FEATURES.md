# Coach App - 구현 기능 정의

## 1. 대시보드 (`/coach/dashboard`)
- 오늘 진행할 수업의 개수 및 시간표 요약.
- 실시간 예약 인원 현황 표시.

## 2. 수업 스케줄 (`/coach/schedule`)
- 날짜별 수업 일정 조회 기능.
- 수업별 상세 정보(장소, 강도, 정원) 확인.

## 3. 회원 케어 및 코칭 노트 (`/coach/members`)
- 회원 검색 기능.
- 회원별 특이사항(부상, 컨디션 등)을 기록할 수 있는 텍스트 기록 시스템.
- 데이터는 `members` 테이블의 `coaching_notes` 컬럼과 연동됩니다.

## 4. 레이스 시스템 (`/coach/race`)
- 실시간 리더보드 중계 및 제어.
- 로잉 머신(PM5) 하드웨어 데이터 연동 및 경기 운영.

## 5. 프로필 및 설정 (`/coach/profile`)
- 코치 개인 정보(전문 분야, 바이오) 조회.
- 로그아웃 기능.
