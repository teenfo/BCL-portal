# 코치 사용 가이드

## 로그인
1. `/coach/auth/login` 경로로 접속합니다.
2. 할당받은 코치 계정(이메일/비밀번호)으로 로그인합니다.

## 오늘 수업 확인
- 대시보드에서 바로 오늘 진행할 수업 목록을 확인하십시오.
- 각 수업의 '출결체크' 버튼을 통해 인원 현황을 파악할 수 있습니다.

## 회원 특이사항 기록
- '회원 케어' 메뉴에서 수업에 참여하는 회원을 검색합니다.
- '노트 작성'을 눌러 해당 회원의 운동 상태나 주의사항을 기록하면 다른 코치 및 관리자와 공유됩니다.

## 스케줄 조회
- '스케줄' 메뉴에서 날짜를 변경하며 미래 혹은 과거의 수업 일정을 확인할 수 있습니다.
