# Kiosk Features

## 1. 무인 QR 체크인 (`/kiosk/scan`)
- **태블릿 전면 카메라 연동**: 별도의 스캐너 없이 태블릿 카메라로 사용자 앱의 QR을 즉시 인식.
- **실시간 유효성 확인**: 만료된 QR이나 미등록 회원의 경우 즉시 시각적/청각적 경고 제공.

## 2. 체크인 성공 피드백 (`/kiosk/success`)
- **회원 정보 요약**: 체크인 성공 시 회원의 이름, 예약된 수업 정보, 멤버십 잔여 횟수(또는 만료일) 표시.
- **자동 복귀 시스템**: 3~5초 후 다시 스캔 대기 화면으로 자동 전환.

## 3. 대기 화면 (Idle Screen)
- **홍보 이미지/영상**: 사용자 상호작용이 없을 때 센터의 프로필이나 공지사항 요약 노출.
- **체크인 시작 버튼**: 대형 버튼을 눌러 스캔 모드로 진입하거나 상시 스캔 모드 유지.

---
## 4. 향후 확장 기능 (Planned)
- **전화번호 체크인**: QR 사용이 어려운 회원을 위한 숫자 패드 입력 기능.
- **신규 방문 상담 신청**: 현장에서 연락처를 남기는 잠재 고객 등록 기능.
