# Kiosk (Check-in Terminal) Documentation

이 디렉토리는 현장에서 태블릿을 활용하여 운영되는 무인 체크인 시스템에 대한 정보를 담고 있습니다.

## 목차

- [주요 기능 정의](./FEATURES.md)
- [키오스크 운영 가이드](./USER_GUIDE.md)

## 주요 결정 사항
- **카메라**: 태블릿 전면 카메라 활용
- **연동**: 사용자 앱(`/apps/checkin`)의 동적 QR 코드와 1:1 연동
