# Kiosk User Guide (운영 가이드)

이 문서는 센터 현장에 설치된 키오스크 단말기의 운영 및 관리 방법을 안내합니다.

---

## 1. 키오스크 시작하기
1.  **단말기 준비**: iPad 또는 안드로이드 태블릿을 가로/세로 거치대에 고정합니다. (전면 카메라가 회원을 향하도록 배치)
2.  **접속**: 브라우저(Chrome/Safari 권장)를 열고 `https://[도메인]/kiosk`로 접속합니다.
3.  **전체화면 설정**: 브라우저 설정에서 '홈 화면에 추가'를 눌러 설치하면 주소창 없이 깔끔한 키오스크 모드로 사용 가능합니다.

---

## 2. 회원 체크인 방법
1.  회원이 본인의 휴대폰에서 **BCL 앱**을 실행합니다.
2.  **'체크인'** 탭을 선택하여 동적 QR 코드를 생성합니다.
3.  키오스크의 카메라 앞에 QR 코드를 15~20cm 거리에서 비춥니다.
4.  **성공**: "OOO님 환영합니다" 메시지와 함께 출석이 완료됩니다.
5.  **실패**: "만료된 QR" 또는 "미등록 회원" 메시지가 뜨면 관리자 데스크에 문의하도록 안내합니다.

---

## 3. 관리자 주의 사항
- **카메라 권한**: 최초 접속 시 브라우저에서 요청하는 '카메라 접근 권한'을 반드시 **허용**해야 합니다.
- **네트워크**: 실시간 DB 연동을 위해 안정적인 Wi-Fi 연결이 필요합니다.
- **청결 관리**: 카메라 렌즈 부위에 지문이나 먼지가 묻으면 인식률이 저하되므로 주기적으로 닦아주십시오.
