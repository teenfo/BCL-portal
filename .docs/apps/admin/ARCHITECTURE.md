# Admin Portal - 기술 아키텍처

관리자 포털은 전반적인 센터 운영 및 데이터 관리를 위해 데스크탑 환경에 최적화되어 설계되었습니다.

## 1. 경로 체계
- **URL**: `/admin/*`
- **소스 코드**: `src/app/admin/*`

## 2. 네비게이션 및 레이아웃
- **Sidebar Navigation**: 왼쪽 사이드바를 통해 모든 주요 메뉴에 접근 가능한 1:1 Sitemap 매핑 구조.
- **Glassmorphism Design**: 시각적 프리미엄을 위한 투명도 효과 및 다크 테마 적용.

## 3. 기술 스택 및 데이터 흐름
- **Next.js (App Router)**: 클라이언트 사이드 렌더링(CSR) 기반의 빠른 전환.
- **Supabase SDK**: 실시간 데이터 동기화 및 관리자 전용 권한(`admin` role) 기반의 데이터 접근.

## 4. 보안 가이드라인
- 모든 관리자 페이지는 `/admin/layout.js` 내의 `AuthGuard`를 통해 보호됩니다.
- 민감한 작업(삭제, 환불 등)은 반드시 한 단계 더 확인하는 보안 절차를 포함합니다.
