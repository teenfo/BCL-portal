# 관리자 운영 가이드

## 기본 사용법
1. 관리자 계정으로 로그인합니다 (`/admin/auth/login`).
2. 왼쪽 **사이드바(Sidebar)**를 통해 필요한 메뉴로 이동합니다.

## 회원 등록 및 관리
- '회원 관리'에서 신규 회원을 등록하거나 기존 회원의 멤버십 잔여 기간을 연장할 수 있습니다.
- 특정 회원의 출결 문제 시 해당 회원의 상세 페이지에서 이력을 확인하십시오.

## 수업 스케줄 생성
1. '수업 일정' 메뉴의 캘린더에서 비어있는 시간대를 클릭합니다.
2. 수업 종류(크로스핏, 요가 등), 담당 코치, 정원을 입력하여 세션을 생성합니다.

## 공지사항 작성
- '공지 관리'에서 새 공지를 작성하면 즉시 모든 회원 앱의 홈 화면과 공지 게시판에 반영됩니다.
- 긴급한 사항은 중요 표시를 통해 상단에 고정할 수 있습니다.
