# 회원 사용 가이드

## 입장하기 (QR 체크인)
1. 앱 하단 중앙의 **체크인(Check-in)** 탭을 선택합니다.
2. 화면에 나타난 QR 코드를 센터 출입단말기에 스캔하여 입장하십시오.

## 수업 예약하기
1. 앱 하단 **스케줄(Schedule)** 탭으로 이동합니다.
2. 원하는 날짜와 시간을 선택한 후, '예약하기' 버튼을 누릅니다.
3. 예약된 내역은 홈 탭이나 스케줄 탭의 '내 예약'에서 확인할 수 있습니다.

## 멤버십 확인
- '프로필' 또는 '멤버십' 메뉴를 통해 본인의 잔여 횟수와 만료일을 실시간으로 확인하십시오.

## 문의하기
- 시스템 이용 중 불편사항은 센터 관리자에게 문의하거나 공지사항의 FAQ를 참조하십시오.
