# User App - 기술 아키텍처

회원 앱은 스마트폰 환경에서의 최상의 사용자 경험을 제공하기 위해 **모바일 퍼스트(Mobile-First)** 원칙에 따라 설계되었습니다.

## 1. 경로 체계
- **URL**: `/apps/*`
- **소스 코드**: `src/app/apps/*`

## 2. 네비게이션 및 레이아웃
- **Bottom Tab Navigation**: 모바일 기기에 최적화된 하단 탭 메뉴(홈, 스케줄, 체크인, 시설, 프로필).
- **Responsive Web**: 다양한 화면 크기에 대응하도록 가변 레이아웃 적용.

## 3. 기술 스택 및 데이터 흐름
- **Next.js CSR**: 페이지 전환 시 새로고침 없는 부드러운 UX 제공.
- **Supabase Public Client**: 익명 키(Anon Key) 및 RLS 정책을 통해 본인의 데이터에만 안전하게 접근.

## 4. 주요 특징
- **QR 기반 서비스**: 입장 체크인을 위한 실시간 QR 코드 생성.
- **실시간 예약**: 수업 정원 확인 및 즉시 예약 가능.
