# BCL Portal 기능 구현 현황 분석 (2026-02-07)

## 1. 전체 요약

이 문서는 `.docs`의 설계 내용과 현재 소스 코드(`src/app`)의 구현 상태를 비교 분석한 결과입니다.
전반적으로 각 포털(Admin, Coach, User, Kiosk)의 기본 라우팅 구조는 sitemap에 맞게 잘 설정되어 있으나, 각 기능별 세부 페이지 구현은 아직 초기 단계에 머물러 있습니다.

---

## 2. Admin Portal (`/admin`)

- **설계 문서:** `apps/admin/FEATURES.md`, `sitemap/bcl-portal-sitemap.md`
- **구현 위치:** `src/app/admin`

### 구현된 기능
- **Dashboard:** `/admin/dashboard/page.js`
- **Attendance:** `/admin/attendance/page.js`
- **Billing:** `/admin/billing/page.js`
- **Check-in Scanner:** `/admin/checkin/scanner/page.js`
- **Coaches:** `/admin/coaches/page.js`
- **Content (Notices):** `/admin/content/notices/page.js`
- **Members:** `/admin/members/page.js`
- **Sessions (Schedule):** `/admin/sessions/schedule/page.js`
- **Settings (Facility):** `/admin/settings/facility/page.js`
- **Support:** `/admin/support/page.js`
- **Auth:** `login`, `callback` 페이지 구현 완료.

### 누락된 기능 (설계 대비)
- **회원 관리:**
  - 회원 프로필 상세 페이지 (`/admin/members/:memberId`)
  - 멤버십/결제 관련 하위 메뉴 (`/admin/billing/plans`, `payments`, `settlements`)는 단일 `billing` 페이지로 통합되어 있어 세분화 필요.
  - 권한/그룹 관리 (`/admin/access-control`)
- **시설·세션 운영:**
  - 예약/대기열 관리 (`/admin/reservations`)
  - 실시간 체크인 현황 (`/admin/checkin/live`)
  - 코치 배정/교체 및 상세 프로필 관리 (`/admin/coaches/:coachId` 등)
- **보고서·분석:**
  - `reports` 관련 모든 기능 (출석, 세션, 매출, 코치 성과)
- **알림·메시지:**
  - `notifications` 관련 모든 기능 (템플릿, 로그, 규칙)
- **통합·연동:**
  - `integrations` 관련 모든 기능 (결제, 웹훅, 데이터 I/O)
- **유지보수·로그:**
  - `audit` 관련 모든 기능 (액션 로그, 에러 로그)

## 4. User App (`/apps`)

- **설계 문서:** `apps/userApps/FEATURES.md`, `sitemap/bcl-portal-sitemap.md`
- **구현 위치:** `src/app/apps`

### 구현된 기능
- **Dashboard:** `/apps/dashboard/page.js`
- **Check-in:** `/apps/checkin/page.js` (QR 생성 기능)
- **Facilities:** `/apps/facilities/page.js`, `[id]/page.js` (목록 및 상세)
- **Membership:** `/apps/membership/page.js`
- **Notices:** `/apps/notices/page.js`, `[id]/page.js` (목록 및 상세)
- **Profile:** `/apps/profile/page.js`
- **Schedule:** `/apps/schedule/page.js`
- **Auth:** `login`, `callback` 페이지 구현 완료.

### 누락된 기능 (설계 대비)
- **스케줄/예약:**
  - 세션 상세 페이지 (`/apps/schedule/:sessionId`)
  - 신규 예약 및 예약 내역 조회 (`/apps/bookings/*`)
- **체크인:**
  - 체크인 기록 조회 (`/apps/checkin/history`)
- **멤버십/결제:**
  - 신규 플랜 구매 (`/apps/membership/plans`)
  - 상세 결제 내역 및 영수증 조회 (`/apps/billing/payments`)
- **프로필/설정:**
  - 보안/계정 관리 (`/apps/profile/security`)
  - 앱 환경설정 (`/apps/settings`)
- **고객지원:**
  - `support` 관련 모든 기능

## 5. Kiosk App (`/kiosk`)

- **설계 문서:** `apps/kiosk/FEATURES.md`, `apps/kiosk/ARCHITECTURE.md`
- **구현 위치:** `src/app/kiosk`

### 구현된 기능
- **Main/Idle Screen:** `/kiosk/page.js`
- `layout.js`가 존재하여 키오스크 전용 레이아웃 적용 준비 완료.

### 누락된 기능 (설계 대비)
- **QR 스캔:** `/kiosk/scan` 페이지 및 카메라 연동 로직
- **체크인 성공/실패 피드백:** `/kiosk/success` 페이지 및 관련 UI
- **확장 기능:** 전화번호 체크인, 현장 상담 신청 기능 (향후 계획)
