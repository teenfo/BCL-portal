# BCL Portal Design & Security System

이 문서는 프로젝트의 시각적 아이덴티티와 시스템 보안 체계를 통합하여 설명합니다.

---

## 1. 디자인 시스템 (Branding & UI)

### 테마 컨셉
- **BCL Orange**: 역동적인 삶을 상징하는 오렌지 컬러(`#FF6B00`)를 메인 액센트로 사용합니다.
- **다크 모드 베이스**: 심야와 운동 환경에 적합한 깊이감 있는 어두운 배경색(`slate-900`대 계열)을 기본으로 합니다.

### UI 구성 원칙
- **Glassmorphism**: 헤더, 카드, 네비게이션 등에 `backdrop-filter: blur` 효과를 적용하여 프리미엄한 감성을 전달합니다.
- **레이아웃**:
  - 관리자: 데스크탑 중심의 좌측 고정 사이드바.
  - 앱: 모바일 중심의 하단 탭 바.

---

## 2. 보안 체계 (Security & Auth)

### 인증 구조 (Supabase Auth)
- **통합 가상 세션**: 모든 접근은 Supabase 서버 세션 검증을 거칩니다.
- **역할 기반 접근 (RBAC)**: 유저 메타데이터의 `role` 값을 기반으로 어드민, 코치, 회원 접근 권한을 엄격히 분리합니다.

### 경로 보호 (AuthGuard)
- 모든 서비스 경로(`/admin/*`, `/apps/*` 등)는 `AuthGuard` 컴포넌트로 보호되며, 비정상 접근 시 해당 서비스의 로그인 페이지로 리다이렉트됩니다.

### 데이터 보안 원칙
- **RLS (Row Level Security)**: 모든 테이블은 RLS가 활성화되어 있으며, 클라이언트 `anon` 키로는 본인 또는 허가된 데이터만 조회 가능합니다.
- **Service Role 사용 금지**: 클라이언트 코드에서 관리자용 시크릿 키를 절대 노출하지 않습니다.

---

## 3. 로그아웃 정책
- `/auth/logout` 경로를 통해 통합 로그아웃을 수행하며, 로그아웃 후에는 이전 서비스에 맞는 로그인 화면으로 안전하게 복귀합니다.
