# Stitch 화면 생성 프롬프트 저장소

이 디렉토리는 Stitch MCP를 사용하여 화면을 생성할 때 사용한 프롬프트를 저장합니다.

---

## 📋 목적

1. **일관성 유지**: 유사한 화면 생성 시 기존 프롬프트 패턴 참조
2. **재사용성**: 성공적인 프롬프트를 템플릿으로 활용
3. **추적성**: 각 화면의 디자인 의도와 생성 과정 기록
4. **협업**: 팀원 간 디자인 방향성 공유

---

## 📝 프롬프트 파일 템플릿

각 프롬프트 파일은 다음 형식을 따릅니다:

```markdown
# [화면명] Stitch 생성 프롬프트

## 메타데이터
- **Screen ID**: [Stitch에서 생성된 Screen ID]
- **생성일**: YYYY-MM-DD
- **Device Type**: MOBILE / DESKTOP / TABLET
- **경로**: [라우트 경로]
- **Sitemap 참조**: [.docs/sitemap 경로]

---

## 생성 프롬프트

[실제 Stitch MCP에 사용한 프롬프트 전문]

---

## 디자인 테마 (고정)
- Color Mode: DARK
- Font: Lexend
- Roundness: 8px (ROUND_EIGHT)
- Primary Color: #ff6a00
- Saturation: 2

---

## 생성 결과
- **상태**: 성공 / 수정 필요
- **수정 횟수**: [횟수]
- **최종 확정일**: YYYY-MM-DD
- **비고**: [특이사항]

---

## 참조 화면
- [유사한 다른 화면명과 경로]
```

## 🎯 사용 방법

### 1. 새 화면 생성 시

1. **유사 화면 찾기**:
   - 동일 영역(apps/admin)에서 기능이 유사한 화면 검색
   - 레이아웃 패턴이 유사한 화면 확인

2. **프롬프트 참조**:
   - 기존 프롬프트의 구조와 표현 방식 파악
   - 공통 요소(디자인 테마, 네비게이션 등) 재사용
   - 화면별 특화 부분만 수정

3. **새 프롬프트 작성**:
   - 참조한 프롬프트 패턴 기반으로 작성
   - 화면 고유 기능 및 레이아웃 추가

4. **생성 후 저장**:
   - 성공적으로 생성된 프롬프트를 해당 디렉토리에 저장
   - Screen ID 및 메타데이터 포함

### 2. 프롬프트 업데이트

- 화면 수정 시 프롬프트 파일도 함께 업데이트
- 수정 이력을 "생성 결과" 섹션에 기록
