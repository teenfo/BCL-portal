# BCL Logo Assets

## Files

- `bcl-logo.svg` - Main logo (vector, preferred)
- `bcl-logo.png` - Main logo (raster backup)
- `bcl-icon.svg` - Icon only (for favicons, app icons)

## Logo Specifications

### Visual Identity
- **Text**: "BCL" in bold, impactful typography
- **Color**: Vibrant orange (#FF6B00)
- **Distinctive Feature**: Kettlebell icon embedded in center "C"
- **Tagline**: "Bundang Crossfit Lounge"

### Usage Guidelines

#### Large Version
- Auth screens, landing pages
- Minimum width: 200px
- Include tagline

#### Medium Version
- App headers, navigation bars
- Minimum width: 120px
- Logo only, no tagline

#### Small Version (Icon)
- Favicons, app icons
- Minimum size: 32x32px
- "B" lettermark or kettlebell icon only

## Color Variants

### Dark Mode
- Logo: Vibrant orange (#FF6B00)
- Background: Transparent or dark charcoal

### Light Mode
- Logo: Vibrant orange (#FF6B00) - same as dark
- Background: Transparent or white

## File Formats

- **SVG**: Preferred for all web usage (scalable, crisp at any size)
- **PNG**: Backup for email, social media (2x resolution for retina)
