## 🔍 화면별 상세 감사

### 1. Insights (운영 현황 및 리포트)

#### 1-1. 대시보드 (`/admin/dashboard`) — 완성도: 70%
**구현 완료:**
- ✅ 실시간 KPI 카드 (오늘 예약, 체크인, 월 매출, 활성 회원)
- ✅ 최근 트랜잭션 / 최근 체크인 목록
- ✅ 위젯 시스템 (Quick Actions, 추가/삭제)

**미구현:**
- [ ] **KPI 트렌드**: 전주 대비 성장률(%) 표시 — 현재 숫자만 표시
- [ ] **긴급 위젯**: 멤버십 만료 임박자 리스트 (7일 이내)
- [ ] **시스템 에러 로그 요약 위젯**: 프론트/백엔드 에러 실시간 감지

#### 1-2. 출석 리포트 (`/admin/insights/attendance`) — 완성도: 60%
**구현 완료:**
- ✅ 30일간 일별 체크인 라인 차트 (SVG)
- ✅ 시간대별 분포 바 차트
- ✅ 체크인 방법별 분포
- ✅ KPI 카드 (총 체크인, 일 평균, 피크 시간, 고유 회원)

**미구현:**
- [ ] **요일별 히트맵**: 요일×시간대 밀도 히트맵 (sitemap 명시)
- [ ] **CSV/Excel 다운로드**: 특정 기간의 전체 입장 로그 추출
- [ ] **기간 필터**: 현재 최근 30일 고정 → 사용자 지정 기간 필터 필요

#### 1-3. 매출 리포트 (`/admin/insights/finance`) — 완성도: 60%
**구현 완료:**
- ✅ 월별 매출 바 차트 (6개월)
- ✅ 카테고리별 매출 비중 (멤버십/PT/상품/기타)
- ✅ KPI 카드 (총 매출, 이번 달, 평균 결제, 환불율)

**미구현:**
- [ ] **결제 수단 통계**: 카드/현금/계좌이체 비율
- [ ] **예상 정산 금액**: 당월 예상 정산 및 전월 대비 추이
- [ ] **기간 필터**: 사용자 지정 기간 필터

### 2. Finance (회원 및 매출 관리)

#### 2-1. 회원 관리 (`/admin/members`) — 완성도: 65%
**구현 완료:**
- ✅ 회원 목록/검색/필터 (상태, 가입일 범위)
- ✅ 가입 승인 대기 탭 (profiles.approval_status)
- ✅ 신규 회원 추가 모달
- ✅ 회원 상세 페이지 링크

**미구현:**
- [ ] **블랙리스트 설정**: 특정 회원 블랙리스트 지정/해제 기능
- [ ] **상담 로그 기록**: 회원별 상담 이력 기록 (member_notes 테이블 연동은 있으나 UI 미흡)
- [ ] **수동 액션**: 이용권 강제 연장 버튼 (members 페이지에서 직접)
- [ ] **회원 등급별 필터**: 현재 상태(Active/Expired)만 필터 → 회원 등급 필터 추가

#### 2-2. 회원 상세 (`/admin/members/[id]`) — 완성도: 70%
**구현 완료:**
- ✅ 기본 정보 카드 (이름, 이메일, 전화, 성별, 생년월일)
- ✅ 보유 멤버십 목록 (상태, 잔여일, 크레딧)
- ✅ 체크인 히스토리 (최근 5건)
- ✅ 결제 히스토리 (최근 5건)
- ✅ 메모/상담 로그

**미구현:**
- [ ] **멤버십 일시정지/재개**: 상세 페이지에서 직접 홀딩 처리
- [ ] **출결 타임라인 전체 보기**: 현재 5건만 → 페이지네이션 or 더 보기
- [ ] **회원 정보 수정**: 이름, 전화번호, 성별 등 직접 수정 기능 없음

#### 2-3. 멤버십 관리 (`/admin/memberships`) — 완성도: 65%
**구현 완료:**
- ✅ 멤버십 목록/검색/필터 (전체/활성/만료/취소)
- ✅ 신규 멤버십 추가 모달 (회원/플랜 선택, 시작일)
- ✅ 크레딧 조정 모달
- ✅ +30일 연장 버튼
- ✅ 홀딩/재개 토글

**미구현:**
- [ ] **이력 추적**: 멤버십 변경 이력 관리 (who, when, what) — 현재 DB 직접 수정만
- [ ] **연장 일수 커스텀**: 현재 +30일 고정 → 사용자 지정 일수
- [ ] **멤버십 양도**: 회원 간 멤버십 양도 승인/처리 기능
- [ ] **정확한 홀딩 처리**: 현재 toggleHold가 status를 단순 토글 → 정식 pause_count 관리, 일시정지 기간 차감 로직

#### 2-4. 요금제 (`/admin/plans`) — 완성도: 80%
**구현 완료:**
- ✅ 플랜 목록 (CRUD)
- ✅ 생성/수정 모달 (이름, 설명, 가격, 기간, 크레딧)
- ✅ 삭제 (확인 다이얼로그)

**미구현:**
- [ ] **정책 설정**: 환급 규정, 홀딩 가능 횟수, 지점 공유 여부 — 현재 Plan 테이블에 해당 컬럼 없음
- [ ] **플랜 타입 구분 UI**: 기간제 vs 횟수제 시각적 분리

#### 2-5. 결제 내역 (`/admin/transactions`) — 완성도: 50%
**구현 완료:**
- ✅ 트랜잭션 목록 (테이블, 필터, 검색)
- ✅ 날짜 범위 필터
- ✅ KPI 카드 (총 매출, 환불, 대기, 건수)
- ✅ 상태/카테고리 필터

**미구현:**
- [ ] **환불 프로세스**: 이용기간 기반 위약금 자동 계산 + 환불 승인 워크플로우
- [ ] **PG 연동**: 실시간 결제 승인/취소 — 현재 수동 데이터만
- [ ] **월간 정산 리포트**: 지점별 순수익 계산, 세금 계산서 기초 자료 생성
- [ ] **CSV/Excel 내보내기**: 트랜잭션 데이터 다운로드

### 3. Operations (클래스 및 현장 운영)

#### 3-1. 수업 캘린더 (`/admin/operations/schedule`) — 완성도: 80%
**구현 완료:**
- ✅ 주간 캘린더 뷰 (06:00~20:00)
- ✅ 세션 CRUD (생성/수정/삭제)
- ✅ 코치 배정 + 중복 배정 방지
- ✅ 정원/WOD 설명/강도 설정
- ✅ 주간 네비게이션 + 오늘 가기

**미구현:**
- [ ] **드래그 앤 드롭**: 시간 조정을 위한 DnD — 현재 모달에서만 수정
- [ ] **정원 규칙**: 대기(Waitlist) 수 설정 — 현재 최대정원만

#### 3-2. 코치 관리 (`/admin/operations/coaches`) — 완성도: 75%
**구현 완료:**
- ✅ 탭 구조 (관리/성과 분석)
- ✅ 코치 목록/검색/상태 필터
- ✅ 코치 등록/수정 모달 (기본정보, 전문분야, 이미지)
- ✅ 성과 분석 탭 (KPI, 랭킹)

**미구현:**
- [ ] **급여/수당 관리**: 수업당 수당 설정 및 월간 정산 금액 계산
- [ ] **코치 계정 연결**: 회원 선택 기반 등록 (Priority 6으로 이미 계획됨)

#### 3-3. 예약 관리 (`/admin/operations/reservations`) — 완성도: 55%
**구현 완료:**
- ✅ 예약 목록 (필터: 전체/대기/확정/취소/출석)
- ✅ 상태 변경 (확정/취소)

**미구현:**
- [ ] **대기열 우선순위 변경**: 관리자에 의한 강제 우선순위 변경
- [ ] **노쇼 통제**: 수업 전 미체크인 회원 경고/페널티(횟수 차감)
- [ ] **세션별 명단 조회**: 특정 세션의 예약 확정자 명단 확인 뷰
- [ ] **검색 기능**: 회원명/세션명 검색 (현재 없음)

#### 3-4. Race 관리 (`/admin/operations/race`) — 완성도: 70%
**구현 완료:**
- ✅ 3탭 (이벤트/기기/기록)
- ✅ Race 이벤트 CRUD
- ✅ PM5 기기 목록 조회
- ✅ 기록 목록 조회 (포맷팅)

**미구현:**
- [ ] **PM5 기기 등록/수정/삭제**: 현재 조회만 가능
- [ ] **기기 상태 모니터링**: 실시간 연결/오프라인 상태
- [ ] **연간 리더보드**: 종목별, 성별 레이팅 — 현재 단순 목록

#### 3-5. 락커 관리 (`/admin/operations/lockers`) — 완성도: 90%
**구현 완료:**
- ✅ KPI 카드 (전체/사용중/빈/만료예정)
- ✅ 락커 CRUD + 배정/해제
- ✅ 회원 검색 배정
- ✅ 필터/검색

**미구현:**
- [ ] **배정 이력 관리**: 과거 배정 히스토리 추적 (locker_assignments 테이블 연동)

#### 3-6. 인프라 (`/admin/operations/infrastructure`) — 완성도: 90%
**구현 완료:** (거의 완성)
- ✅ 키오스크 CRUD, 메시지 설정, KPI, 시설 연동 모두 완료

**미구현:**
- [ ] **고정 QR 생성**: 센터 입구 비치용 상시 체크인 QR 코드 생성/다운로드

#### 3-7. 역할 관리 (`/admin/operations/roles`) — 완성도: 70%
**구현 완료:**
- ✅ 역할 목록 + 권한 매트릭스
- ✅ 역할 추가 모달
- ✅ 권한 토글 (DB 저장)
- ✅ 사용자 수 표시

**미구현:**
- [ ] **역할 삭제**: 시스템 역할이 아닌 커스텀 역할 삭제 기능 없음

- ✅ 알림 히스토리 조회/필터

- ✅ 티켓 상세 보기 패널
- ✅ 상태 변경 (접수→처리중→해결→종료)

**미구현:**
- [ ] **답변 기능**: 관리자 답변 작성/전송 기능 없음 — 상태 변경만 가능
- [ ] **FAQ 관리**: 자주 묻는 질문 등록/편집/삭제 + 앱 자동 노출
- [ ] **알림 연동**: 티켓 답변 시 회원에게 알림 발송
- [ ] **KPI 카드**: 접수/처리중/해결 건수 요약

#### 4-4. 피드백 관리 (`/admin/crm/feedback`) — 완성도: 55%
**구현 완료:**
- ✅ 피드백 목록 (수업/코치/회원 JOIN)
- ✅ 별점 표시 + 코멘트 조회

- [ ] **통계 대시보드**: 월간 만족도 추이, 코치별 평균, 키워드 분석
- [ ] **필터**: 코치별/수업별/날짜별 필터링 (현재 없음)

**미구현:**

- [ ] **연휴 휴무일**: 휴무일 일괄 등록
- [ ] **이용 약관 관리**: 서비스 이용약관, 개인정보 처리방침, 환불 규정
- [ ] **지도 연동**: 좌표 기반 지도 표시
- [ ] **센터 이미지**: 인테리어 이미지 관리

**구현 완료:**
- ✅ 환경 변수 읽기 전용 표시 (하드코딩된 모의 데이터)

- [ ] **연결 테스트 실제 구현**: Supabase/PG/PM5 연결 확인 로직
- [ ] **API/Webhook 엔드포인트 관리**: 외부 서비스 연동 CRUD

#### 5-3. 사이트 설정 (`/admin/setup/settings`) — 완성도: 85%
