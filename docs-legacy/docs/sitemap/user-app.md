# User Application Design Module (`/apps/*`)

이 문서는 일반 회원용 모바일 웹 앱의 화면 구조, 주요 기능 및 기술적 설계를 통합 관리하는 정본(SSOT) 기획서입니다.

---
> [!NOTE]
> 전체 서비스 구조 및 공통 라우팅 규칙은 [**Global Sitemap Index**](./README.md)를 참고하십시오.


## 1. 📱 네비게이션 및 화면 구조 (Bottom Tab)

회원용 앱은 한 손 조작이 용이하도록 하단 탭 네비게이션 기반의 모바일 퍼스트 디자인을 따릅니다.

### 1) Home (`/apps/dashboard`)
- **수업 요약**: 본인의 오늘 예약/체크인 상태 및 다음 수업 스케줄 명시.
- **주요 소식**: 지점 긴급 공지사항 및 개인별 알림 피드.
- **멤버십 정보**: 이용 중인 플랜 종류 및 만료일 D-Day 표시.

### 2) Schedule (`/apps/schedule`)
- **수업 캘린더**: 주간 단위 수업 목록 조회 및 코치/난이도별 실시간 필터링.
- **예약 프로세스**: 실시간 예약, 대기열(Waitlist) 등록 및 원클릭 취소.
- **내 일정**: 과거 참여 이력 및 예정된 예약 내역 통합 관리.
- **WOD 및 서킷 구성 뷰어**: 
  - 예약 전 오늘의 WOD 종류 및 구성 상세 미리보기 지원.
  - WOD가 `station_circuit` 형태인 경우, 가로 카드 덱 스크롤 타일로 구성된 스테이션 순환 순서 및 배정 5분 가이드 표시.

### 3) Check-in (`/apps/checkin`)
- **QR 체크인**: 입장 단말기 태깅을 위한 실시간 동적 QR 코드 생성.
- **출석 월력**: 본인의 월간 출석 데이터 및 운동 통계 시각화.

### 4) Facilities (`/apps/facilities`)
- **지점 안내**: 운영 중인 전 지점 정보(운영 시간, 주소, 지도, 편의시설) 조회.
- **데이터 연동**: 관리자 포털의 실시간 지점 설정 동기화.

### 5) Profile (`/apps/profile`)
- **내 정보**: 기본 프로필 수정, 앱 설정(다크모드 등) 관리.
- **구독/결제**: 현재 이용권 상세, 잔여 횟수 확인 및 과거 결제 영수증 조회.
- **알림 설정** (`/apps/profile/notifications`): 
  - In-App / Push / 카카오 / SMS / Email 채널별 수신 on/off
  - 카테고리별 알림 수신 설정 (수업 리마인더, 빈자리, 멤버십 만료, 프로모션 등)
  - iOS PWA 설치 안내 (Push 알림 활성화를 위함)
- **고객 센터**: 1:1 문의 채널.

### 6) Notifications (`/apps/notifications`) 🆕
- **알림 히스토리**:
  - 모든 알림 (In-App, Push) 통합 조회
  - 카테고리별 필터 (수업, 빈자리, 멤버십, 프로모션 등)
  - 읽음/미읽음 상태 표시
  - 딥링크 지원 (알림 탭 시 해당 화면 이동)
- **실시간 수신**:
  - Supabase Realtime 기반 즉시 알림 도착
  - 토스트 팝업 (앱 상단, 5초 자동소멸)
  - 미읽음 배지 (Dashboard 벨 아이콘)

## 2. 🛒 추가 화면 (Additional Screens)

### 6) 멤버십 구매 (`/apps/purchase`) 🆕
- **요금제 목록**: 
  - 카드 형태로 모든 멤버십 플랜 노출
  - 기간제 / 횟수권 구분
  - 가격, 기간/크레딧, 혜택 표시
- **플랜 상세**: 
  - 선택한 플랜의 자세한 설명
  - 환불 규정, 홀딩 정책 안내
- **결제 프로세스**: 
  - 결제 수단 선택 (카드, 계좌이체, 간편결제)
  - PG사 연동 (Toss Payments, NicePay)
  - 결제 완료/실패 피드백
- **구매 완료**: 
  - 멤버십 활성화 즉시 확인
  - 영수증 이메일 발송

### 7) 피드백 제출 (`/apps/feedback`) 🆕
- **수업 후 평가**: 
  - 참여한 수업 자동 목록화
  - 별점 (1-5점) 선택
  - 리뷰 텍스트 작성 (선택)
  - 코치 평가
- **제출 완료**: 
  - 피드백 감사 메시지
  - 포인트 적립 (선택적)
- **내 피드백 조회**: 
  - 과거 작성한 모든 피드백
  - 관리자/코치 답변 확인

### 8) 운동 기록 (`/apps/records`) 🆕
- **WOD 기록 입력**: 
  - 수업별 기록 입력 폼
  - For Time / AMRAP / Weight 등 타입별 입력
  - 사진 첨부 (선택)
- **개인 PR 관리**: 
  - 종목별 최고 기록
  - PR 갱신 히스토리
  - 달성 배지
- **운동 히스토리**: 
  - 월간/연간 참여 수업 통계
  - 진행 그래프 (출석, 기록 향상)
  - 목표 설정 및 추적

### 9) 배지 (`/apps/badges`) 🆕 ✅ 구현 완료
- **구현 파일**: `src/app/apps/badges/page.tsx`
- **배지 컬렉션**: 운동 성취 배지 목록 조회
- **획득 조건**: 배지별 달성 조건 안내
- **배지 상세**: 획득일, 달성률 등 세부 정보

### 10) 코치 디렉토리 (`/apps/coaches`) 🆕 ✅ 구현 완료
- **구현 파일**: `src/app/apps/coaches/page.tsx`
- **코치 목록**: 센터 소속 전체 코치 프로필 조회
- **전문 분야**: 코치별 전문 분야, 바이오 확인
- **코치 상세**: 담당 수업 및 스케줄 연동

### 11) 리더보드 (`/apps/leaderboard`) 🆕 ✅ 구현 완료
- **구현 파일**: `src/app/apps/leaderboard/page.tsx`
- **WOD 랭킹**: 종목별 기록 순위 조회
- **카테고리 필터**: 성별, 연령대, 기록 타입 필터
- **개인 PR 표시**: 본인 기록 하이라이트

## 3. 🛠️ 기술 아키텍처 및 UI 원칙

### 기술 스택
- **Architecture**: Next.js CSR 기반의 모바일 특화 반응형 레이아웃.
- **Data Layer**: Supabase `anon key` 및 RLS 정책을 통한 안전한 본인 데이터 접근.
- **Security**: 모든 라우트 접근 시 세션 유효성 자동 검증.

### 디자인 원칙
- **Mobile-First UX**: 하단 탭 배치 및 엄지손가락 조작 반경 내 중요 액션 버튼 배치.
- **Glassmorphism**: BCL Orange 아이덴티티를 강조하는 반투명 유리 질감의 프리미엄 UI.

## 🚀 4. 회원 사용 가이드 요약 (User Guide)
- **입장하기**: 앱 하단 중앙 '체크인' 탭을 누르고 QR을 입구 단말기에 스캔하세요.
- **수업 예약**: '스케줄' 탭에서 원하는 날짜를 선택하고 '예약하기'를 누르면 완료됩니다.
- **멤버십 구매**: '프로필' → '구매하기'에서 원하는 요금제를 선택하고 결제하세요.
- **피드백 남기기**: 수업 참여 후 '피드백' 탭에서 별점과 리뷰를 작성하세요.
- **기록 입력**: '기록' 탭에서 오늘의 운동 결과를 입력하고 성장을 추적하세요.
