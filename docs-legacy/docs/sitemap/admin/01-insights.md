# Admin Portal - 운영 현황 및 리포트 (Insights)

본 모듈은 시설의 건강 상태를 수치화하여 데이터 기반의 의사결정을 돕는 분석 도구를 제공합니다.

---
> [!NOTE]
> 공통 기술 아키텍처 및 디자인 원칙은 [**Admin Index (README)**](./README.md)를 참고하십시오.


## 🖥️ 주요 화면 및 기능

### 1. 종합 대시보드 (`/admin/dashboard`)
- **실시간 KPI**: 현재 센터 내 입장 인원, 오늘 세션 예약 총계, 미확인 알림 건수.
- **트렌드 요약**: 주간 방문자 추이 및 전주비 성장률 그래프.
- **긴급 위젯**: 멤버십 만료 임박자 리스트 및 시스템 에러 로그 요약.
- **🧩 위젯형 Quick Actions**: 커스터마이징 가능한 위젯 기반 빠른 액션 시스템.
  - 상세: [Dashboard Widget System 설계서](./dashboard-widgets.md)

### 2. 출석 리포트 (`/admin/insights/attendance`)
- **패턴 분석**: 요일별/시간대별 방문 밀도 히트맵(Heatmap).
- **데이터 추출**: 특정 기간의 전체 입장 로그를 CSV 또는 Excel로 다운로드.

### 3. 매출 리포트 (`/admin/insights/finance`)
- **매출 구성**: 요금제별 매출 비중(기간제 vs 횟수권) 및 결제 수단 통계.
- **예상 정산**: 당월 예상 정산 금액 및 전월 대비 매출 변화 추이.

### 4. 수업 피드백 분석 (`/admin/insights/feedback`) 🆕
- **만족도 모니터링**: 수업별 평점 트렌드 및 회원 코멘트 실시간 확인.
- **코치별 통계**: 코치별 평균 평점 및 피드백 개수 비교 분석.
- **피드백 필터링**: 불만족(낮은 평점) 피드백 우선 분류 및 관리자 답변 기능.

> **Note**: 코치 성과 분석은 [`Operations > Coaches`](./03-operations.md) 페이지의 "성과 분석" 탭으로 통합되었습니다.
