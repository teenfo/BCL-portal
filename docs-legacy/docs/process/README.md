# Process & Governance

이 디렉토리는 BCL Portal의 **반복 가능한 운영 절차**를 정의합니다.
신규 기능 기획이 아니라, 프로젝트 자체의 일관성을 유지하기 위한 메타-문서입니다.

## 사용 시점

- **신규 기능 기획 시작**: Documentation Governance §3.1 템플릿 사용
- **릴리즈 준비**: Release Checklist 복사하여 PR/이슈에 첨부
- **분기 정기 점검**: Documentation Governance §5 항목 수행
- **감사 수행**: Documentation Governance §1.2 참조 규칙 준수
