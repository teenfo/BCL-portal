Personal Record - QR 기반 스마트 짐 트래킹 시스템 기획
개요
짐 내 모든 기구에 QR 코드를 부착하여, 회원이 스마트폰으로 스캔하는 것만으로 운동 데이터를 자동 수집하거나 수동 입력할 수 있는 통합 운동 기록 시스템.
시스템 아키텍처
[짐 내부 서버 (BCL Portal)]
  ├── PM5 등 BLE 기기와 상시 연결
  ├── 포털 웹앱 호스팅
  └── 로컬 네트워크 기반 저지연 통신

[사용자 흐름]
스마트폰으로 QR 스캔
  → 로컬 서버에 기기 식별 및 계정 바인딩 요청
  → 기구 타입에 따라 자동 수집 또는 수동 입력 UI 표시
  → 운동 데이터 서버 저장 → 히스토리 및 통계 제공
QR 코드 설계
각 기구의 QR 코드에는 다음 정보를 인코딩한다.
https://bcl-portal.local/track?equipment=ERG_001&type=rowing
https://bcl-portal.local/track?equipment=BARBELL_RACK_01&type=barbell&base_weight=20
equipment : 기구 고유 ID
type : 기구 타입 (rowing, barbell, kettlebell, pullup 등)
base_weight : 해당 기구의 기본 중량 (선택, 바벨 등에 활용)

바인딩 흐름 (로잉머신 예시)
1. 사용자가 로잉머신 QR 스캔
2. 포털 로그인 확인 (미로그인 시 로그인 페이지 이동)
3. 서버에 바인딩 요청 POST /api/bind { equipment_id, user_id }
4. 서버가 해당 PM5와 BLE 연결 및 데이터 수집 시작
5. 웹앱에서 실시간 운동 데이터 표시 (페이스, 스트로크, 칼로리 등)
6. 운동 종료 감지 또는 사용자 종료 → 자동 언바인딩 및 기록 저장
수동 입력 흐름 (바벨 예시)
1. 사용자가 바벨 랙 QR 스캔
2. 종목 선택 UI 표시 (스쿼트 / 데드리프트 / 벤치프레스 등)
3. 중량 입력 (base_weight 자동 반영, 원판 무게만 추가 입력)
4. 세트 / 렙 입력
5. 저장 → 다음 세트 이어서 입력 가능
6. 운동 종료 시 전체 볼륨 및 세트 기록 저장
