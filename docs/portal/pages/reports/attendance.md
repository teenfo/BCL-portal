# 출석 리포트 (Attendance Reports)

## 1. 개요
- **경로**: `/admin/reports/attendance`
- **아이콘**: `fa-chart-bar`
- **설명**: 전반적인 출석률, 피크 시간대 분석 등 출석 데이터를 시각화하여 제공하는 리포트 화면입니다.

## 2. 주요 기능
- 일별/주별/월별 방문자 수 추이 분석
- 요일별/시간대별 혼잡도 통계
- 지점별 출석 데이터 비교 분석

## 3. UI 컴포넌트
- 혼잡도 히트맵 (Heatmap)
- 출석 추이 라인 차트
- 주요 통계 위젯 (Avg. Daily Attendance 등)

## 4. Database Requirements (DB Schema)

### 기초 데이터 테이블
이 리포트는 아래 테이블들의 데이터를 집계하여 생성됩니다.

- **`attendance_logs`**: 방문객 및 체크인 시간 데이터의 원천
- **`sessions`**: 수업별 정원 대비 출석률 계산을 위한 기초 데이터
- **`users`**: 회원별 방문 빈도 및 연령/성별 통계 분석용

### 집계 정보 (Aggregated View)
실시간 집계 성능 향상을 위해 일별/시간대별 통계 뷰(View) 또는 집계 테이블을 활용할 수 있습니다.
