## P1 — 매출·법규 직결

### 1. 일일권·드롭인·무료체험 상품 (비회원 판매) — P1
- 근거: 크로스핏 박스 표준 문화(드롭인·1회 체험). 바디코디는 키오스크 무인 일일권 판매 지원
- 현황: **없음** — plans type 2종(period/count)뿐. 키오스크 검증이 "활성 멤버십 없으면 NO_MEMBERSHIP 거부"(06 §4.2)라 드롭인 방문자는 체크인 자체 불가
- 권고: 누락 시 현장 운영 즉시 수기 회귀

### 2. 환불 위약금 산정 법규 정합성 — P1 ⚠️설계 결함
- 근거: 공정위 위약금 산정기준·소비자분쟁해결기준 — 체육시설 중도해지 위약금 **총 계약대금 10% 이내**+이용일수 공제. 소비자원 조정에서 10% 초과 공제 반복 부당 판정
- 현황: **부분(위험)** — 08 §1.6 기본값이 "1/2 경과 전 20%, 1/2 경과 후 환불 불가"로 명시 → 현행 분쟁 실무와 충돌, 패소·시정 리스크
- 권고: refund_policy JSONB 오버라이드 구조는 기존재 — **기본값을 10% 상한형으로 교정**(환불금 = 결제금액 − 이용일수 해당액 − min(위약금, 결제금액×10%))

### 3. 현금영수증 발급·의무발행 관리 — P1
- 근거: 헬스장은 현금영수증 **의무발행 업종**(국세청) — 10만원 이상 현금거래 5일 내 발급 의무, 미발급 시 거래액 20% 가산세. Toss 현금영수증 API 존재
- 현황: **없음** — 수동 결제 등록(source=manual)에 현금영수증 개념 전 문서 0건. 현장 현금/이체 매출 무방비
- 권고: transactions에 발급 상태·승인번호 필드 + 미발급 경고 리포트

## P2 — 국내 공통 기능

### 4. 미수금(부분 수납·분할 납부) 관리 — P2
- 근거: 다짐매니저·바디코디·핏투비·페이소프트 공통 — 일부 입금 후 잔액 추후 수납이 현장 관행
- 현황: 없음 — transactions 단건 완납 전제, 멤버십:결제 1:1
- 권고: 멤버십 1건-결제 N건 매핑(약정액 vs 수납액) + 미수 대시보드·자동 알림

### 5. 회원 계약서·환불규정 전자서명(동의 증빙) — P2
- 근거: 모두싸인 헬스장 태블릿 전자계약 상품화, 바디코디 공식 연동. 분쟁 시 "환불규정 고지·동의" 증빙이 핵심 방어
- 현황: 부분 — facilities 약관 "문서"만, 회원별 동의·서명 레코드 없음
- 권고: canvas 서명 캡처+동의 스냅샷 테이블 경량 구현

### 6. PT·개인레슨 세션권 — P2 (판매 시 P1 승격)
- 근거: 포인티·어시스트핏 등 PT 전용 CRM 시장 별도 존재 — 수업권 차감·코치 매칭·세션 확인·커미션 정산 표준
- 현황: 없음 — 그룹 정원제·정액 정산만
- 권고: BCL PT 판매 여부 확인 후 결정. 미판매면 확장 여지만

### 7. 자동 메시지 시나리오 확장 — P2
- 근거: 다짐매니저 "18가지 상황 자동 메시지"(재등록 유도·생일·등록 감사·장기 미출석·락커 만료 이벤트)
- 현황: 부분 — 만기 D-7/3/1·리마인더·빈자리·락커 만기는 있음. 만기 "이후" 재등록 유도·생일·등록 감사·장기 미출석 자동 발송 없음
- 권고: notification_rules+pg_cron 프레임에 규칙 3~4종 추가 — 저비용 고효과

## P3 — 후순위
- 8. 네이버 플레이스/예약 리드 유입(바디코디 차별점, 다짐 마켓) — 단일 박스면 후순위. 최소: 체험 신청 폼+리드 상태
- 9. 출입 하드웨어(스피드게이트·안면인식 — 슈프리마 연동) — 코치 상주 수업제라 니즈 낮음. fn_kiosk_checkin 응답에 개방 신호 확장점만 문서화
- 10. 정기결제(카드 빌링/CMS 자동이체 — 효성CMS·페이소프트) — 의도적 제외 타당. 재검토 시 CMS 계좌 자동이체(비 PG 경로) 포함 여부 명기
- 11. 락커 이용료·물품 대여 상품화 — 배정·만기 알림만 있고 요금·결제 연계 없음(락커 매출 장부 밖). 부가상품 타입 또는 lockers-transactions 연결로 경량 해소
